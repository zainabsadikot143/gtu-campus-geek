# gtu-campus-geek
AI-powered GTU Student Assistant using RAG and Gemini API.
## Objective
To help GTU students access syllabus, exam information, FAQs, study plans, and academic guidance using AI and Retrieval-Augmented Generation (RAG).

## Technology Stack
- React
- Tailwind CSS
- FastAPI
- Gemini API
- ChromaDB
- Supabase
